# استوديو أبو قمر

نسخة تأسيسية فعلية بـ Next.js وReact وTypeScript. واجهة عربية RTL، محرر Canvas، رفع عدة صور أصلية، تعديل الاسم والوزن والسعر، حساب الخصم، تحريك وتكبير وتدوير وشفافية، ترتيب وإخفاء وقفل الطبقات، تراجع وإعادة، حفظ محلي تلقائي باستخدام IndexedDB، مكتبة منتجات، إعادة فتح المشاريع، تصدير PNG/JPG وZIP مع النصوص وCSV.

## التشغيل

Node.js 24، npm 11:

```sh
cd /workspace/abu-qamar-post-studio
npm ci --cache /tmp/abu-qamar-npm-cache --no-audit --no-fund
npm test
npm run typecheck
npm run build
npm start
```

للتطوير: `npm run dev`. المنفذ الافتراضي 3000. عند ظهور EPERM للاتصال بالبروكسي أو عمليات البناء، استخدم صلاحية تنفيذ مناسبة؛ لا تعطل TLS ولا تتجاوز البروكسي.

## الهوية

لم تصل ملفات «هوية سوبر ماركت أبو قمر.html» أو الخلفية المرجعية. لا يحتوي المشروع على شعار بديل أو قالب يدّعي أنه رسمي. ارفع الشعار والخلفية المعتمدين من إعدادات الهوية، واضبط اللون والخط وفق الملف الأصلي. قفل الهوية يمنع تعديل هذه الحقول حتى تأكيد فك القفل. التصدير محجوب إلى أن تتوفر الصورتان. لا يُعد القفل المحلي نظام صلاحيات أمنيًا.

## حدود النسخة الحالية

- التخزين داخل المتصفح فقط، دون حسابات أو مزامنة. احفظ المشروع من زر الحفظ لإضافته لقائمة المشاريع، والحفظ التلقائي يحفظ جلسة العمل. نزّل نسخة JSON احتياطية؛ استيراد النسخ الاحتياطية لم يُنفذ بعد.
- التصميم الجماعي والقوائم يستخدمان حاليًا المحرر المشترك مع عدة منتجات وتوزيع شبكي؛ طوابير المعالجة وقوائم الأيام ونسخ الأمس والتصفية حسب الفئة لم تنفذ بعد.
- مكتبة القوالب تنتظر الأصول المعتمدة؛ الاقتراحات الثلاثة غير مكتملة.
- العزل وOCR وتحسين الصور والتعديل النصي وخدمة Supabase والمصادقة وحدود الاستخدام غير مربوطة. واجهة هذه الخدمات تعرض عدم توفرها بوضوح ولا ترسل الصور خارجيًا.
- القص وتصحيح الحواف والشارات وتعديل كل طبقة نص على حدة والظلال المتقدمة لا تزال مطلوبة.
- راجع مواضع العناصر يدويًا قبل التصدير؛ يمكن أن تتداخل النصوص عند كثرة الأصناف. الخلفية تملأ المقاس مع الحفاظ على النسبة وقد تقص حوافها.
- لم يتم نشر الموقع. لا تحفظ مفاتيح API في واجهة المتصفح.

## التحقق

`npm test` يغطي صحة الخصم وعدم اختراع معلومات الكابشن وتهريب CSV. فحص Chromium مستقل تحقق من رفع أصول اختبار ورفع منتج وتعديل السعر وحفظ/إعادة فتح وتصدير PNG وZIP. أصول الاختبار في /tmp فقط، وليست هوية رسمية أو جزءًا من المستودع.

## تحديث القالب المرفق

اعتُمد ملف «هوية سوبر ماركت أبو قمر.html» المرفق واستُخرج الشعار PNG دون تعديل بايتاته، وخطا Cairo وTajawal مع تراخيصهما في public/brand. ألغيت الخلفية الجدارية والمنصة وشرط رفع الخلفية بناءً على طلب المستخدم. مساحة الإعلان شفافة في PNG وبيضاء في JPG. قالب Canvas يستخدم ألوان الملف وعنوان التوفر والاسم وشارة السعر وشريط التواصل؛ تُحفظ بيانات المشاريع المحلية القديمة دون حذف، ويُتجاهل رسم خلفيتها السابقة. المقاسات الأخرى تعيد توزيع القالب نسبيًا. تعليمات غياب الهوية أعلاه تصف الحالة السابقة لهذا التحديث.
